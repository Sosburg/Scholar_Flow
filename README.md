# Scholar_Flow
A simplified version of Atlas, which allows researchers to save qoutes from a particular research article or book. This however include students who want to take notes of certain wordings in a book.
The purpose of this project was to create a simplified verison of Atlas.pi. 
Atlas.ti is a powerful computer-assisted qualitative data analysis software (CAQDAS) used by researchers, students, and organizations to organize, code, and analyze large bodies of textual, graphical, audio, and video data. It helps users uncover complex patterns, build thematic networks, and manage qualitative information efficiently. Includes the following data types:
  - Text & Documents: PDFs, Word files, e-books, and interview transcripts
  - Multimedia: Audio recordings and video files
  - Visuals: Images, photographs, and diagrams
  - External Data: Survey data, social media feeds, and web pages
